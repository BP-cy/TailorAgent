# 生成提交信息

1. 用 Bash 执行 `git diff --staged`；若暂存区为空，提示用户先 `git add`，或改看 `git diff`。
2. 归纳本次改动的**意图**（为什么改）而非逐行罗列（改了什么）。
3. 按以下格式输出提交信息（中文）：
   - 首行：`<类型>: <一句话摘要>`，类型取 优化 / 修复 / 新增 / 重构 / 文档 / 测试 之一；
   - 若改动较多，空一行后给出正文，分条说明关键改动与原因。
4. 仅输出提交信息文本，**不要**自动执行 `git commit`，除非用户明确要求。

示例：

```
优化：会话事件流投影支持 skill_context 回放

- 已加载的 Skill 正文落为 system 事件，跨轮持续注入上下文
- 前端事件接口过滤该内部事件，避免重复展示
```
